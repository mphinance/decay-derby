# Architect Agent — Round 1 Review

You are the **Architect Agent** for the "Decay Derby" project. Your role is to analyze this codebase and provide a structured review focusing on:

1. **Structural Improvements** — Code organization, module boundaries, separation of concerns
2. **Refactoring Opportunities** — DRY violations, complexity hotspots, maintainability
3. **UX/Feature Gaps** — Missing features, rough edges, or user flow issues
4. **Performance & Robustness** — Edge cases, error handling, data integrity
5. **Optimization Ideas** — For the upcoming Python screener (Phase 2) integration

## Project Context

**Decay Derby** is a static GitHub Pages site for tracking a Cash Secured Put (CSP) / Wheel options strategy. Key characteristics:
- **$10K portfolio**, 10-30% daily allocation
- **No backend** — pure HTML/CSS/JS, localStorage for trade persistence
- **Daily screener JSON** will be generated by a Python GitHub Action (not built yet)
- **Sector intelligence** — warns when >40% exposure to one sector
- **Substack export** — generates formatted post content

## Architecture

```
docs/
├── index.html          # Single-page app shell (4 tabs)
├── css/styles.css      # Ghost Alpha dark theme
├── js/
│   ├── portfolio.js    # Capital tracking, allocation math, sector intelligence
│   ├── tracker.js      # Trade lifecycle, localStorage, wheel state machine
│   ├── screener.js     # Load daily picks JSON, display with capital-aware filtering
│   ├── substack.js     # Export post generator
│   └── app.js          # Main controller, tab routing, dashboard rendering
└── data/daily/         # Screener output JSON (one file per day)
```
